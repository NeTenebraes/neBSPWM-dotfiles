# 🚀 Roadmap & WIP

Este documento detalla las funcionalidades en desarrollo y las metas a futuro para **neBSPWM**. Las tareas están priorizadas según su impacto en mi flujo de trabajo.

## 🏗️ En Desarrollo (Alta Prioridad)
- [ ] **Instalación Modular:** Opción en `setup.sh` para elegir qué componentes instalar (solo bspwm, solo herramientas de sec, etc.).
- [ ] **Selector de Temas:** Script integrado en Rofi para cambiar entre variantes *Mocha, Macchiato y Frappe*.

## 📅 Próximas Metas (Backlog)
- [ ] **ISO Personalizada:** Crear una imagen `.iso` pre-configurada basada en Archiso.
- [ ] **Wiki de Herramientas:** Documentación sobre cómo usar los contenedores de Firejail incluidos.
- [ ] **Rediseño del Power Menu**: Se está explorando la opción de rediseñar el power menu con eww.

## ✅ Completado
- [x] **Soporte Multimonitor:** Script para autodetectar pantallas y ajustar Polybar dinámicamente.
- [x] Integración de **Caido** y **Burp Suite** en el menú de aplicaciones.
- [x] Dashboards de Conky con estadísticas de red en tiempo real.
